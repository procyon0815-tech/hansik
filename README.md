# Korean Cuisine Practical Test Learning App

## Introduction
This project is a learning application designed to help users prepare for the Korean Cuisine Craftsman Practical Test.

The app provides study materials for Korean cuisine practical exam items, including cooking procedures, key points, time management, and important precautions. It helps learners understand the correct cooking process and practice efficiently before taking the practical exam.

## Main Features
- Provides learning materials for Korean cuisine practical test items
- Helps users study step-by-step cooking procedures
- Supports time management practice for the practical exam
- Organizes key cooking points and common mistakes
- Allows repeated review before and after cooking practice

## How to Use
1. Download this repository.
2. Run the project.
3. Select a Korean cuisine practical test item.
4. Study the cooking steps, time limit, and key points.
5. Review the content repeatedly to prepare for the practical exam.
